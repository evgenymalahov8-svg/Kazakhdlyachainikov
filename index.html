    ЗАЧЕМ ЭТОТ САЙТ?

    Начать новый язык с нуля непросто: непривычные буквы, звуки и правила. Платные курсы есть не у всех.

    Сайт ведёт по шагам: один урок в день, теория всегда закрепляется практикой, а слова возвращаются на повторение. Проект начался с казахского: его сделала студентка, которая сама учит язык и не хотела платить за курсы. Теперь здесь есть и английский.

    Каждый курс устроен по-своему, но правило одно: теория — сразу в практику. Прогресс по каждому языку хранится отдельно.

    Курсы: «Казахский для чайников» и «Английский для чайников». Немецкий, французский и японский появятся позже.
    Прогресс: сохраняется в этом браузере, отдельно для каждого языка, и не синхронизируется между устройствами. Платных разделов нет.
    Кто сделал: студентка, которая поступила учиться в Республику Казахстан и сама не казашка. Казахский и английский для автора не родные, поэтому в текстах возможны ошибки. Сайт не заменяет учителя и не выдаёт сертификатов.
